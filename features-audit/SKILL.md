# Features Audit

## Goal

FIND ALL FEATURES THE PROJECT HAS AND CENTRALIZE THEM IN AN EASY TO UNDERSTAND AND SORTED markdown file FOR END USERS!

## Process

0. GOAL: FIND ALL FEATURES THE PROJECT HAS AND CENTRALIZE IT
1. STUDY THE CODE!
2. Create upsert (CREATE/UPDATE) the `FEATURES.md`
3. BE BRUTALLY HONEST!
4. Include the state of the feature: FULLY_FUNCTIONAL, PARTIALLY_FUNCTIONAL, BROKEN, PLANNED or whatever makes sense!

## Execution

```
READ, UNDERSTAND, RESEARCH, REFLECT.
Break this down into multiple actionable steps. Think about them again.
Execute and Verify them one step at the time.
Repeat until done. Keep going until everything works and you think you did a great job!
```
