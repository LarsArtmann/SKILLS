# Launch Checklist — T-14 to T+7

Copy this file into the project and tick boxes. "Launch" = the public
spike (Show HN / Product Hunt / Reddit); the soft launch precedes it.

## T-14 — the asset is ready

- [ ] Sales page follows the 9-section arc; 5-second test passed by 2 people
- [ ] Headline matches the audience's awareness stage
- [ ] Founding offer published with a real, countable limit
- [ ] Guarantee + refund policy linked from pricing
- [ ] Full buy path tested with a REAL card in live mode (then refunded)
- [ ] Analytics events firing: visit, signup_start, signed_up, activated, paid
- [ ] Session replay running on landing + signup pages

## T-10 — warm soft launch

- [ ] 10-20 personal messages to warm network / beta users (founding terms)
- [ ] Everything that breaks within 48h gets fixed BEFORE the spike
- [ ] First testimonials requested from active soft-launch users

## T-7 — one community post

- [ ] Niche community chosen (problem's home, not r/SaaS)
- [ ] Post = honest build story with numbers; link in comments, not title
- [ ] Account has genuine history (9:1 rule) — else borrow time: participate NOW, delay this channel

## T-3 — prime the list

- [ ] Waitlist email #2 sent: date, what to expect, founding count remaining
- [ ] Demo GIF (≤30s) recorded for PH gallery
- [ ] Show HN title drafted: "Show HN: <product> — <one-line what it does>"

## Day 0 — launch morning

- [ ] Post early (HN morning EU/US overlap; PH 12:01am PT)
- [ ] First comment posted by the maker within minutes (build story / "what's interesting")
- [ ] Warm audience notified — no upvote asks, ever
- [ ] Founder's ONLY job today: answer every comment, every email, every chat
- [ ] Watch signups live; if onboarding leaks, fix it TODAY mid-spike

## Day +1 / +2 — keep answering

- [ ] Thank-you/receipt email to the list (numbers, rank, what's next)
- [ ] Every unanswered thread closed
- [ ] Objections heard in comments → FAQ entries (same day)

## Day +3 — second spike

- [ ] Product Hunt (never same day as another launch): gallery, GIF, maker
      first comment, 24h of answers, badge on site afterward

## Day +7 — retro (30 min)

- [ ] Funnel numbers vs medians (SaaS LP 3.8%; free→paid ~9%)
- [ ] Biggest single leak identified → next week's ONE fix
- [ ] Directories batch submitted (one-time)
- [ ] Decide: next channel, or double down on the one that produced
