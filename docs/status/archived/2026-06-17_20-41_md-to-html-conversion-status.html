d) TOTALLY FUCKED UP!

Pre-commit formatter side effects

The repo's pre-commit hook reformats Markdown files after my edits, which means the committed file sometimes differs from what I intended. So far it has only standardized table alignment and whitespace, but it creates uncertainty — I have to re-verify after each commit. This is a process smell, not a code smell.

README count mismatch

My first pass claimed 19 skills; the actual count is 20. I fixed it in the second pass, but the fact that I had to fix it means my mental model of the directory tree was wrong.

  5. Document the pre-commit formatter in AGENTS.md so future agents know to re-verify after committing.
