DTotally Fucked Up

Honest assessment of what is broken, wrong, or regrettable.

Honest · Self-inflicted

The palette WAS the Tailwind defaults — for months

Fixed this session

The html-report-kit shipped with indigo (#6366f1) on slate-900 (#0f172a) — literally Tailwind's stock colors. This is the single most recognizable "AI-generated" palette in production. It took a user revolt ("I hate the colors") and a 15-design shootout to fix it. The kit is supposed to be the design standard for all skills — it was setting the worst possible example.

Fixed: Bauhaus adopted. But the lesson is: never ship a design system with default framework colors. A design system's job is to have an opinion.
Architectural · Fixed

The token split brain that survived 3 audits

html-output-guide.md — fixed this session

The dark template used --bg-elevated, --rose, --emerald. The light template used --bg-card, --coral, --teal. Same concepts, different names. This was documented in the guide as if it were intentional ("both class vocabularies are aliased"). It was not a feature — it was a split brain that made markup non-portable between themes. It survived at least 3 status reports without being flagged as a structural defect.

GTop #1 Question I Cannot Figure Out

Blocking · Needs your input

Should the Bauhaus templates use Google Fonts when the report is for public consumption?

html-report-kit design requirements

The Bauhaus look derives its personality from heavy font weights (800/900) and tight tracking. System fonts approximate this well — but they don't match the showcase designs you approved. The showcase files that won your approval (06c-bauhaus-desktop-v3.html) used Archivo and Space Mono from Google Fonts. The canonical templates now ship with system font stacks only, per the kit's zero-dependency rule.

This means every report generated from the canonical templates will look slightly less distinctive than the design you actually chose. The system-font version is good — but it's not the version that made you say "Bauhaus is the winner."

The tradeoff: System fonts = zero dependencies, works offline, instant load. Google Fonts = matches the approved design, more personality, but adds an external request and breaks the zero-dependency promise. I cannot determine which matters more to you: design fidelity or dependency purity. The answer determines whether I add the <link> to the canonical templates or leave them system-only.
