## T22/T23 — environment discoveries (NixOS)

- The system `node` is a shim (`exec bun "$@"`); sharp refuses to load under
  bun 1.3.13 (baseline build) → all HyperFrames CLI invocations must run
  under `nix shell nixpkgs#nodejs`.
- `PUPPETEER_EXECUTABLE_PATH` and PATH-chromium are both ignored: the CLI
  always launches puppeteer's cached chrome-headless-shell; that binary
  needs ~25 NixOS shared libs via `LD_LIBRARY_PATH` (full recipe now in
  `demo-video.md`, gated by `ldd` returning zero "not found").
- `go install` is blocked by the agent sandbox; `go run pkg@version` and
  `go build -o <project-local>` are the workarounds.
