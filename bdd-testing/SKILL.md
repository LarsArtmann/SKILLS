# BDD Testing

## Process

1. Understand this project and your customers needs.
2. Think about which Behavior-driven development (BDD) Tests we should add!
3. Use onsi/ginkgo to actually implement them.
4. Make sure they are ran via `go test` too!
5. MOST importantly ALL our tests should be (end-)user focused!

## Execution

READ, UNDERSTAND, RESEARCH, REFLECT.
Break this down into multiple actionable steps. Think about them again.
Execute and Verify them one step at the time.
Repeat until done. Keep going until everything works and you think you did a great job!
