00Summary

The new editorial-light template gives long-form review reports a warm, readable, professional look. It keeps the zero-dependency rule while adding a sticky sidebar TOC, issue cards with file metadata, recommendation callouts, and ASCII dependency trees.

The bottom line Use the editorial template for adoption feedback, architecture reviews, and audit briefs. Keep the dark dashboard template for status snapshots and scan results.

◆What's already excellent

+
Single-file, zero dependencies Both templates work offline with system fonts. No CDN, no build step, no JS.
+
Shared component vocabulary Issue cards, callouts, scorecards, and dep-trees use the same class names across themes.
+
Responsive sticky sidebar Desktop readers get a contents nav; mobile readers get a clean single-column layout.

01Findings

Resolved · Low impact

Dark and light templates used different class names for the same component

html-report-kit/assets/report-template.html · report-template-editorial.html

The dark template originally called metrics .stat-grid / .stat-card; the light template called them .scorecard / .score-card. Both names now work in both templates, so markup can be swapped between themes without rewrites.

Fix: added cross-theme aliases Keep the existing classes for backward compatibility and use whichever name reads better in your report.
Aesthetics · Medium impact

System fonts approximate but do not match Space Grotesk / JetBrains Mono

Both templates

The go-output report that inspired this template loads Google Fonts. The shared kit deliberately avoids external requests, so reports look slightly less distinctive on machines without modern system fonts.

Security · Low impact

Consider adding a CSP meta tag example

html-output-guide.md

Because the templates are inline-style only, a strict Content-Security-Policy is easy to add. A short example in the guide would help security-conscious users.

02What the unified API could look like

If both templates shared component class names, a skill author could switch themes by swapping the template file without rewriting markup. 

<div class="scorecard">
  <div class="score-card score-good">
